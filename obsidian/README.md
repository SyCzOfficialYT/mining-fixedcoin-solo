# FixedCoin Solo — Obsidian Brain

This folder is the project's **Obsidian vault**.

Open `obsidian/` as a vault in Obsidian. The vault is deliberately Markdown-first so the project knowledge remains portable, Git-friendly and readable without Obsidian.

## Start here

- [[00 - Home]] — project control center
- [[10 - Architecture]] — system map and data flow
- [[20 - Stratum]] — mining protocol, difficulty and miner compatibility
- [[30 - Dashboard]] — LiveShare / Arcane Forge UI
- [[40 - Block Pipeline]] — share → candidate → submit → block
- [[50 - GhostBot]] — webhook automation and message contract
- [[60 - Operations]] — Docker, deploy and diagnostics
- [[70 - Incidents]] — troubleshooting history
- [[80 - Decisions]] — architectural decisions
- [[90 - Roadmap]] — next work

## Rule

If a change affects consensus, Stratum, miners, dashboard, deployment or operations, document the **why** here, not only the code.
